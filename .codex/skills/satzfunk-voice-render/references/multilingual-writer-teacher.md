## Conversational intake for writers, educators and language learners

Help a user state the **outcome** before exposing implementation options. Use one brief clarification only when essential information is missing; do not turn onboarding into a long form. Reuse supplied text, chosen language, intended audience and voice identity. Distinguish:

- **Read an existing text:** The written text is immutable authority. The teacher or writer may supply their own original text and a target language/accent; a translation is a separate authored revision requiring their acceptance before a recording can be source-locked.
- **Create an own-voice edition:** Ask for the speaker's authorization and permitted use of a reference recording. A voice reference is private biometric-like material and is not a license to copy another person's voice. Never manufacture an authorization or infer authorization from possession of a file.
- **Teach across languages:** Identify source and target language separately, audience and learning aim (e.g. pronunciation practice, bilingual read-along). A teacher using their *own* voice to teach pupils is different from cloning pupils' voices; do not demand children's voice samples or route learner recordings to a provider. For minors, use educator-owned or properly licensed recordings by default; any actual pupil voice collection requires separately established guardian/school consent and applicable protection.
- **Native British-English ambition:** Distinguish preserved speaker identity from native Standard Southern British English pronunciation and literary prosody. Cross-language cloning may preserve a source accent. Never label a generated take "native" from a vendor claim; a qualified native listener must assess target pronunciation and rhythmic naturalness alongside identity/performance comparison.

Suggested minimal interaction: “Please read my essay in my own voice, but with natural British English.” -> establish authorized speaker reference and original text (if not already present), then check the selected owner-native model/provider's **actual** implementation. “Make a French listening lesson in my voice for my class.” -> establish teacher's rights to source and reference, learners' level and delivery language, with accessible written text; do not ask for pupil voice recordings.

## Source-owned execution

1. Resolve the current repository phase, authorized host, active source SHA-256, speaker reference rights, intended voice identity, audience, exact target language/accent, cost choice and the **currently functioning** renderer/ASR. Inspect its real API contract, model availability, checkpoint license and available hardware. Do not assume a research model has been installed or its protocol matches GPT-Live; no implicit API spend.
2. If the request fits the existing selected approved narrator route, use the existing instrument and documented execution procedure. If **own-voice cloning, cross-language voice transfer or self-hosted synthesis** is requested but no qualifying owner-native adapter exists, classify it as **NOT ESTABLISHED**, not as a completed recording, and give the exact smallest instrument/provider integration action. Do not invent an ad-hoc Python/HTTP recording backend, silently switch voice, or take unapproved audio from a public recording.
3. Obtain the applicable speaker authorization and writer cost/provider decision through the current host admission. A conversation or voice sample alone is not persistent consent. Make the privacy and any cloud transfer transparent. Bound paid attempts and protect private voice references, originals, candidate WAVs and receipts.
4. Generate/retain source-addressed candidate WAV only on a genuinely available, authorized route. Check the spoken text using independently observed waveform recognition, not the generator's self-reported transcript. Do not force source words into ASR prompts to manufacture a match. Test foreign names and meaningful omissions/substitutions.
5. For own-voice/native-language claims, compare unchanged source references, private candidate audio and independent native-listener judgments of pronunciation, voice identity, prosody and long-form continuity. Word timestamps from a forced aligner are timing estimates, **not proof that the utterance matches the manuscript**. Never assert exact MIDI 2.0 cursor sync without a run against the existing cursor.
6. Produce accessible written source and meaningful audio controls/labels, including original language and intended pronunciation locale; retain a text-equivalent route for learners. Do not create a second Linotype transcript/Continuous reader, alter pagination, autoplay, or conflate a class handout with public publication.
7. Read back source/audio digests, exact model/voice and permission identity, elapsed audio, independent fidelity and artistic status, rights and release decision. Report **documented**, **tested in fixtures**, **heard/accepted**, **staged**, and **publicly published** separately. Installation in ChatGPT or Claude does not supply runtime execution or acceptance.
