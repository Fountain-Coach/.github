**Editorial rule adopted 13 November 2026.** The approved opening of *The Model Is Not the Instrument* establishes the correct **treatment** of authored editorial introductions, not a requirement to add editorial prose to every page. ## Before changing a book or estate

1. Inventory actual source and active release; distinguish an **authored editor introduction**, **work abstract**, **authorial subtitle**, **first paragraph**, **series introduction**, **normative Governance text** and **missing editorial content**. Infer none from font size, position or word count. Never generate missing prose or overwrite owner authority.
2. Reuse Fountain Press `Scripts/editorial_proem.py` / `contracts/editorial-proem.v1.schema.json` at the pinned `Fountain-Coach/fountain-press` revision for deterministic document-level projection. The algorithm only converts one already marked `p.frame-essay-abstract[data-editorial-role=abstract]` to one separate `aside.frame-editorial-proem[data-editorial-role=proem]`. Existing asides remain unchanged. `frame-lead` remains an author-owned opening or subtitle. No second CSS/JS renderer, model-written summary or new FCIS-KIT.
3. Preserve original text and `data-source-block`/offsets, alt/caption/illustration, original chapter and volume identity, and original collection membership. The editorial label is **reader interface furniture**, never part of source prose. Keep the aside in the measured single Reading Frame after the principal art and before narrative. On no-hero works it sits immediately before prose.
4. Refuse duplicate or ambiguous proems and invalid addresses. Transform a complete **admitted** publication composition into a separate candidate, not a released live source tree. Run deterministic source hash/output hash audit and idempotence checks.
5. Compose with the established Linotype engine. Inspect actual iPad portrait, landscape, phone and source-address retention. Verify editorial label, italic scale, rule, proem **once**, opening prose availability, image position and no overflow. Check each changed static direct route, original book index and unchanged social hero; preserve intact non-editorial routes. Browser tests are not physical iPad proof.
6. Record exact source and Press instrument commits, affected route hashes, unchanged manuscript/media facts, staging predecessor, publisher receipt and independent HTTPS readback. Only EstatePublisher authorizes immutable staging and distinct public production. Do not upgrade a candidate or a Git commit into release authority.

**Estate scope:** applies wherever a source-owning publication has opted into the common Fountain Press Linotype composition, including older/archived reference essays and the First Readings series. It does **not** make every estate hostname a book, impose labels on Governance normative chapters, or edit separately owned Teatro/Satzfunk applications.
