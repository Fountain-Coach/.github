# FCIS — Name and Identity

**Status:** Adopted naming and runtime-independence clarification (12 November 2026)
**Owner:** Fountain Coach
**Canonical expansion:** Fountain Coach Instruction System
**Acronym:** FCIS
**Normative authority:** [RFC 0001 — Orthogonal Instruction Architecture](../profile/README.md)

FCIS names Fountain Coach's organization-owned instruction architecture. The acronym and the four instruction layers defined in RFC 0001 are unchanged: `AGENTS.md`, `PLANS.md`, Skills, and MCP servers.

The name refers to **Fountain Coach**, not to an individual model, agent, or vendor. **FCIS-MODEL-1** in RFC 0001 makes model and agent providers independent of Fountain Coach instruction and capability authority. OpenAI Codex may be used through an admitted adapter; it is never required to apply the FCIS contract. Fountain Coach does not claim ownership of hosted or local model-service infrastructure simply by using it.

The 12 November naming correction introduced no new requirements. The subsequent **v1.5.0** clarification explicitly decouples model-provider requirements from RFC 0001 without adding a fifth layer or claiming new implementations. It does not grant model access, subscriptions, portability or any runtime capability. The canonical source is the [Fountain-Coach/.github organization profile](../profile/README.md); the [organization GitHub Pages site](https://fountain-coach.github.io/) mirrors that source and must be regenerated from it, not independently edited as a second authority.

Use **Fountain Coach Instruction System (FCIS)** when expanding the acronym in present-tense organization documentation. Preserve accurate tool-specific references to Codex when they describe an actual integration or historical execution context; do not elevate such references into organization-wide requirements.
