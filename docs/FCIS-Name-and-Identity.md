# FCIS — Name and Identity

**Status:** Adopted naming clarification (12 November 2026)
**Owner:** Fountain Coach
**Canonical expansion:** Fountain Coach Instruction System
**Acronym:** FCIS
**Normative authority:** [RFC 0001 — Orthogonal Instruction Architecture](../profile/README.md)

FCIS names Fountain Coach's organization-owned instruction architecture. The acronym and the four instruction layers defined in RFC 0001 are unchanged: `AGENTS.md`, `PLANS.md`, Skills, and MCP servers.

The name refers to **Fountain Coach**, not to an individual model, agent, or vendor. OpenAI Codex remains an execution context referenced by the adopted RFC; its appearance in operational or historical documentation does not make it part of the FCIS name.

This is a **naming correction**, not a new RFC, capability claim, agent-integration mandate, modification to existing obligations, or version change. The canonical source is the [Fountain-Coach/.github organization profile](../profile/README.md); the [organization GitHub Pages site](https://fountain-coach.github.io/) mirrors that source and must be regenerated from it, not independently edited as a second authority.

Use **Fountain Coach Instruction System (FCIS)** when expanding the acronym in present-tense organization documentation. Preserve accurate tool-specific references to Codex when they describe an actual integration or supported execution context.
