# FCIS Skill custody and publication boundary

**Owner decision: 24 November 2026.** A Skill is private owner/customer knowledge by default. Creating, learning, editing, versioning, restoring or admitting a Skill is not publication. FountainStore is the canonical custody and revision authority for newly created private Skills. FCIS Console is its management surface; Git and model providers are optional, explicitly selected publication adapters. Source engineering plans and contracts remain in their existing Git authority. A public Git repository is a publication surface, including branches, pull requests, diffs, CI logs and history.

- Keep private Skill content and intermediate revisions out of public Git, provider projections and public issue/PR text. Use the existing owner-authorized native Store release path once its private contract is admitted. A local private staging file may bridge the transfer; do not call staging canonical or admission complete before independent readback. Do not substitute an ordinary private Git repository as the default customer knowledge Store.
- Public distribution requires an explicit owner decision identifying the exact admitted revision, intended audience, visibility, licence/terms, and selected provider. A private or monetized Skill must never be projected by default. Commercial entitlement and scoped execution authority remain distinct; payment is not publication.
- FCIS-GO 0.1.40 is the one existing public distribution. Its current Git source and projection are retained during transition. Nine previously exposed legacy trees are historical compatibility exceptions, maintained without widening distribution; they are not a precedent for new private authoring. Preserve their verified history and provenance. Their eventual Store migration is a separate reviewed operation; do not pretend they have become confidential by moving them.
- The accidental public FCIS Console Development source from PR #128 is removed from the current public tree; its historical exposure is irreversible by ordinary deletion. Do not publish its payload again. Private admission v0.1.0 and exact signed source readback are LIVE-VERIFIED in [runtime PR #203](https://github.com/Fountain-Coach/midi2-gpu-fabric/pull/203#issuecomment-7129506220). Store sequence 4 to 5; existing public release unchanged. Private authoring UI and commercial distribution remain separate work. Do not rewrite public history, delete the repository or alter the public plugin identity as a side effect.
- The existing source checks and managed Git hooks refuse unapproved Skill package paths before publication. CI is a secondary check after upload, not a confidentiality barrier. The path guard cannot detect arbitrary sensitive prose in otherwise allowed files; keep private bytes entirely outside public authoring workflows. No automated promotion or expansion of the published marketplace inventory.

No live billing or commercial distribution is authorized by this custody decision. Preserve the P0 owner-independence journey and the existing public FCIS-GO release while implementing the private Skill slice.
